# Getting Started with Vibe Coding

## Pre-Requisite Software

1. OpenCode (opencode.ai) is a terminal-based agent. 

    > Note: We will be trying our exerises with OpenCode V2.

    To install it, follow the instructions on their website: <https://opencode.ai/v2/docs>.

2. [Visual Studio Code](https://code.visualstudio.com/)

3. [Git - Version Control Software](https://git-scm.com/)

4. [NodeJS](https://nodejs.org) - We'll need this for exercise 5.

4. [GitHub account](https://github.com) (Optional)
