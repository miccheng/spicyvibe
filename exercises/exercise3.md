# Exercise 3: Vibe Code via Prompting

First, let's try to do some **"Prompt Engineering"**. OpenCode is an AI Agent with a chat interface - so we speak to the agent like you would to a co-worker (eg. Direct Message). The AI (in this case, the Large Language Model (LLM)) are sophisticated enough to understand your natual language instructions and the intent of your instructions - and translate that into computer instructions for software code.

The instruction we give to AI in a natual language is called a "prompt" - as in "we are prompting the AI to do something".

## Build a simple web app

1. In OpenCode, type (or just copy & paste) the text below into the text box :

    Pick one of the following:

    - > Build a simple web app where a user types in their current mood (e.g., 'Tired', 'Celebratory', 'Lazy') and the app suggests a 3-ingredient recipe. Make sure to include a photo of the recipe.
    - > I want a simple "Grocery Check list" web application to keep track of my grocery shopping. Store the data locally in the browser.

    Feel free to include any other requirement in the prompt. Like what color should the web app be using. What style should it have.

2. See what happens.

3. Feel free to tell OpenCode to fix whatever is not working:

    - Image is not showing.
    - The search box and the result are not aligned.

4. Use VScode to see what was added to the `vibeprojects` folder.

5. You can double-click on the `index.html` to see the result in the web browser.
