# Bonus Exercises: 

## Exercise A: Add web hosting

> _**Note:** Folks using VIBER Studio may skip to the next exercise as your app is already viewable online (it is hosted on Rabbit Deploy)._

Let's try and host the application on [GitHub Pages](https://docs.github.com/en/pages).

### Using a System Prompt

Use this system prompt to check with your coding agent:

> How might I host this application on GitHub Pages. Show me the instructions and make the changes so that I can do this.

### Using OpenSpec

Use this 

> /opsx:propose I would like to make this application sharable with others. It should be hosted on GitHub Pages.

And then:

> /opsx:apply

...to implement.

## Exercise B: Add a Database

Think about how you might want to add a database to one of the vibe coded applications you build today.

### Using a System Prompt

Use this system prompt to check with your coding agent:

> How might I add a database to this application so that I can share the link with someone else.

### Using OpenSpec

Use this 

> /opsx:propose I would like to make this application sharable with others. Results should be stored on a database.

And then:

> /opsx:apply

...to implement.
